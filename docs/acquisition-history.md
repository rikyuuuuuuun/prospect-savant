# LINEの流入経路

表示先はスタッフ画面の「実入会の推移」タブ。チーム概要にグラフや流入KPIを追加しない。全体・A〜E別・月別の3択の割合、回答数と未取得数を表示する。割合の分母は回答済みの申込人数（子ども単位）で、1件の兄弟同時申込も子どもごとに数える。未取得を「その他」へ推定しない。集計開始は2026-11-02、以後は年度開始との遅い方から基準日までの受信日基準。紹介者名が空欄でも明示した紹介回答は紹介へ分類する。

非公開取得では既存の正本リンクから中央受付を解決し、受付キー・受信日時・チーム・種別・抽出方法・機械生成の備考だけを読む。自由記入の文言を経路に推定しない。受付単位のテスト・運営者除外を守り、日付未確定の申込は申込集計へ含める。読取後の再読一致を必須にする。取得失敗は未取得状態として表示し、0人に置き換えない。

公開するのは定義・基準日・期間・タイムゾーン・各分類の匿名件数だけ。個別受付キー、日時、原文、紹介者名、自由記入、内部のファイルIDやURLは公開しない。既存の日次公開で全スナップショットの整合性を検証し、公開済みポータルの分析バンドルへ反映する。

紹介ポイントの正本は従来の会員マスター集計。実出席・子ども1人1ポイント・兄弟姉妹・人物の重複排除を保持し、明示した紹介回答を紹介者名より優先する。明示がない旧記録は従来の有効な紹介者入力で判定する。Eは流入分析だけに含め、A〜Dの既存スコア体系へ追加しない。
