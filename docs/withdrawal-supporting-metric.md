# 退会の補助指標

2026-09-06の承認に基づく。総合点・定着力の採点には使わない。

## 正本と判定

中央会員マスター `01` の退会日・人物ID・所属、`02` の契約コース終了履歴、`08` の在籍状態変更履歴を読取専用で集計する。会員や契約の状態は書き換えない。公開ファイルには月別の人数・根拠別件数・未確定件数のみを保存し、IDや個人情報を含めない。

優先順位は退会日、課金停止日、契約コース停止検知日。現在の中央シートには課金停止日の専用項目がないため、実連携では退会日と停止検知日を使用する。課金停止日の専用入力は集計関数で受け付けるが、APIから取得済みとは扱わない。停止検知日は日次同期でコース消失を検知した日であり、実際の退会日とずれる可能性がある。

休会・退会予定・未来の退会は当月の退会にしない。一部コースだけの終了や、同一人物が別アカウントで在籍を続けるケースを除外する。退会履歴は人物・月で重複排除する。記録された退会後に再入会しても、その退会履歴を残す。履歴のない過去の再入会を推測で再構成しない。人物の所属が競合する履歴はチームへ推定配分せず別記する。

## 人数と率

棒グラフは退会月が判明した人数。確認0人は退会ゼロの確定を意味しない。

月次退会率は「月初在籍者のうちその月に退会した人数 / 月初運用会員数」。当月入会・退会は人数には含むが、率の分子には含めない。分母は同一定義・前月末の既存Savantスナップショットからのみ取得する。未来は未集計。過去月の月初人数が未取得の場合は算出保留。

退会月不明が残るチーム・入会日不明が分子に影響する月・所属未確定履歴がある場合は保守的に率を保留し、0%で埋めない。前月差は両月の率があるときだけ表示する。年度は4月〜翌3月。履歴修正や名寄せが反映されたときは過去の判明人数も再集計される。

## 更新・検証

日次の非公開Sheets取得パイプラインで必要な列を読み、匿名集計を2回比較する。読み取り途中の変更は公開しない。公開時は同じ基準日の月初人数を適用し、既存の4データファイルとmanifestを一括で検証・公開する。旧形式の取得結果は古い退会データを持ち越さない。

新規テストは優先順位、検知日補完、休会・移動・コース変更の除外、未来、同月入退会、人物重複、所属競合、再入会後の履歴、算出保留、個人項目拒否、読み取り中変更を確認する。

## 2026-09-06 表示方針の変更（追加承認）

不明分による算出保留を公開画面の基本表示にせず、判明分だけから参考割合を算出する。月初分母と月初在籍の判定が揃う月は判明コホート退会数/月初人数。月初人数や入会日が不十分な過去月は、判明退会人数/公開基準日会員数として別の見出しと計算式を明示する。欠落した人数を推測で分子へ加えない。実データの未確定件数はそのまま表示する。比較は同じ分母基準の月同士だけに限定する。

この参考値は公開ページで匿名の人数から算出する。元データの厳格な `rate` 判定は保持するが、公開画面の算出保留には使用しない。総合スコアは変更しない。
