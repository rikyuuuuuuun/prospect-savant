# スタッフ向けSavantの連続相対評価

公開bundle生成時に検証済みの匿名実績から表示用の点数を計算する。Sheetsと公開元データ、過去履歴、元データ照合は変更しない。画面の採点方式は`continuous-soft-rank-v2`。旧方式の点数と直接比較しない。

定着・年度入会・成長・紹介の各実績を、他チームとの1対1の比較点の平均で評価する。実績差が大きい場合は比較点を0/100に近づけ、同等に近づく途中ではなめらかに50点へ近づく。順位を抜く瞬間の段差は設けない。最上位・最下位を一定点に固定しない。チームの実績・順位を指定して点数を調整することはない。

対象指標ごとに、比較可能な全チームで共通の幅`w = (実績最大 - 実績最小) * 0.2 + 実績平均 * 0.01`を使う。自分と相手の実績差を`d`として比較点は`50 * (1 + d / hypot(d, w))`。相手を入れ替えた比較点の合計は100。同じ実績なら50。自分自身は比較相手に含めない。微小な差だけで0/100になることを避け、2チームしか比較できない期間にも順位を抜く前の連続変化を持たせるため、幅に水準項を加える。

全員ゼロなら0点。比較対象なし・実績未取得はnull。全員同じ正の実績なら50点。全チームの実績が同じ倍率になれば点数は不変。指標内の実績の大小と相対点の大小は一致する。他チームの変化によっても点数は変わる。

- 定着：継続人数/対象人数。既存の採点対象期間・対象20人以上・比較可能2チーム以上・期間重み1〜8を維持。
- 年度入会：年度の実体験→入会人数/実体験人数。前年率は説明用。
- 成長：既存の大会上位30%加重点。
- 紹介：紹介人数相対点70%＋紹介率相対点30%。紹介率の分母は基準日の運用会員数。
- イベント：従来の歴代MAX正規化、一般会員対象のみ、参加70%＋継続30%。

総合は丸め前の指標と既存配点30/20/20/15/15から計算し整数に四捨五入。各指標、総合、点差、前回差分は整数表示。表示総合が等しければ同順位。細かい改善が毎回1点になるとは限らない。表示可能な点数に達した時に動く。

前回公開の匿名実績も同じ計算で再評価する。元スコア版や指標定義が異なる場合は既存の比較除外を維持。上位との差と、同じ比較相手への差が前回より縮んだ整数点を表示する。元データが不足する場合は推測しない。

`build-staff-pages.mjs`が毎朝の公開と表示変更の公開で共通して呼ばれる。画面の全セクションは同じ投影済みデータを参照する。`data.js`等の元データとmanifestはそのまま保持し、投影後HTMLのSHA-256をbundleに付ける。ポータルの既存OIDC更新処理がbundleを保存する。
