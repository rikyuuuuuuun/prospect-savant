# 実退会日時が未確定の場合の公開

2026-10-11、元集計が実際の名簿退会日時を正とする仕様へ変わり、過去日時が不明なチームの継続率が空欄になった。公開処理が定着力・総合点を必須数値としていたため、`SOURCE_VALUE_INVALID` で他の指標も更新停止した。

- 既存の匿名退会精度欄を厳密に読み、確認済み件数・不明件数と基準日を公開データに記録する。根拠のない空欄、式エラー、矛盾する率は引き続き拒否する。
- 実退会日時が不明なチームの定着力・12か月継続率・定着曲線・学齢継続率は `null`。0点や古い値で補わない。
- 定着力が欠けるチームの総合点と、全チームの総合順位を保留する。その他の検証済み指標は同じ基準日で公開し、manifestを `partial` にする。
- UIは「確認中」を表示し、不明値の増減・強弱評価を行わない。退会日の定義が異なる過去値と定着力・総合点を比較しない。
- 7ファイルの一括公開、ハッシュ検証、個人情報検査、元データの日付・品質チェックは維持する。

中央ダッシュボードの定着力期間点も、対象数に加えて継続率が数値であるチームだけを順位母集団に含める。未確認率は比較対象から除外し、比較可能チームが2未満なら点数を出さない。日時データが揃えば、次回の既存更新経路で再計算される。

## n8nの適用範囲

今回のジョブは起動・Google取得とも成功し、数値変換で停止した。実行をn8nへ置き換えても同じ空欄と必須数値の矛盾は残る。n8nの再試行・エラーワークフローは一時的通信障害の復旧や通知には利用できるが、未確定データの意味はこの公開契約で扱う必要がある。n8n実機への移行・接続試験はこの修正に含めていない。
