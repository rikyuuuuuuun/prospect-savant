# 会員構成

「会員構成」メニューで全体・A〜Dの学年相当、在籍期間、男女比、年齢層、在籍状態、入会年度を切り替える。人数と割合、平均・中央値の在籍期間、入会3か月未満・在籍3年以上の割合とチーム比較表を表示する。スコア計算には加えない。

## 集計元と定義

`scripts/member-composition.mjs`が、既存の非公開連携先から会員マスターの会員キー、人物キー、在籍状態、生年月日、登録性別、入会日、主チームと、承認済み運用会員設定だけを読む。氏名・連絡先・会場名は取得しない。URLやIDは既存の私的連携式から解決し、公開コードに埋め込まない。

- 既存`buildOperationalRoster`を使用し、在籍・休会・退会予定の人物単位会員を再構成する。複数契約は1人とし、現在有効な承認済み所属補正・会費ペイ外例外を適用する。
- 全体と各チームの人数が同日の既存運用会員数と完全一致することを必須とする。すべての分布の合計とチーム合計も検証する。
- 学年欄は現状空欄のため使用しない。生年月日と4月始まりの年度から学年相当を算出する。4月2日〜翌4月1日生まれを同一学年とし、4月1日に進級する。
- 在籍期間は有効な入会日の最古日から基準日までの満月数。休会期間を含む。月末入会者は短い月の末日を月の到達日とする。平均・中央値は入会日判明者だけを対象にする。
- 入会年度は4月〜翌3月。現在の会員を入会年度で分類した値であり、過去の全入会者数ではない。
- 生年月日や性別が重複レコード間で矛盾する場合、未登録・不正・未来日の場合は該当属性を不明にする。会費ペイ外例外で属性がない会員も分母から除かない。
- 在籍状態は有効チームの契約に在籍があれば在籍、次に退会予定、次に休会を優先する。
- 割合の分母は選択対象の全運用会員。不明を含め100%（丸め誤差あり）。

## 公開と欠損時の動作

私的読取結果は同一の列を再読し、生データと連携先の不変性を確認する。外へ出る値は固定スキーマの匿名集計だけ。個人単位のキー・生年月日・入会日は出力しない。

`fetch-private-savant-source.mjs`が日次の同一基準日で取得し、`publish-private-savant-source.mjs`が`data.js.memberComposition`へ反映する。旧入力に集計がなければ過去の構成を引き継がない。取得失敗・所属未解決・人数不整合時は当日分を明示的にunavailableとし、画面は確認中を表示する。欠損を0に置き換えず、検証済みの既存指標は更新を継続する。

`validate-snapshot.mjs`は日付・会員定義・人数・各分布・平均の整合と固定フィールドを検証する。公開4データファイルとmanifestを同一snapshot IDで更新し、既存7ファイルを一括配備する。`build-staff-pages.mjs`のスタッフ向けbundleに同梱する。
